# 🧙 Mythoria

> Découvrez un univers fantastique de cartes à collectionner, de boosters magiques et de créatures légendaires.

## 📖 Présentation du projet

**Mythoria** est un site web inspiré des jeux de cartes à collectionner. Il permet aux utilisateurs d'explorer un univers fantastique, d'acheter des boosters, de découvrir de nouvelles cartes, de gérer leur collection et de construire leur propre deck.

Ce projet est réalisé dans le cadre d'une formation en développement web afin de mettre en pratique les compétences en HTML, CSS, Tailwind CSS, JavaScript et Git.

## 🎯 Objectifs du projet

- Créer une interface immersive et responsive.
- Développer une page d'accueil attractive.
- Présenter différentes catégories de cartes et des boosters.
- Créer une boutique avec un panier interactif.
- Simuler l'ouverture de boosters avec des probabilités de rareté.
- Permettre la gestion d'une collection de cartes dans le Grimoire.
- Permettre la création et la gestion d'un deck.
- Sauvegarder les données avec `localStorage`.
- Publier le projet sur GitHub et le déployer sur Vercel.

## 🛠️ Technologies utilisées

- **HTML5** — Structure des pages web.
- **CSS3** — Mise en forme, animations et responsive design.
- **Tailwind CSS** — Création d'interfaces modernes.
- **JavaScript** — Interactivité et manipulation du DOM.
- **Git** — Gestion des versions.
- **GitHub** — Hébergement du code source.
- **Vercel** — Déploiement du site web.

## ✨ Fonctionnalités

### 🏠 Accueil
- Navigation entre les différentes pages.
- Section Hero présentant l'univers de Mythoria.
- Présentation des catégories de cartes et des boosters.
- Mise en valeur des cartes légendaires.

### 🛒 Boutique
- Présentation des boosters disponibles.
- Sélection des quantités.
- Ajout et suppression d'articles dans le panier.
- Calcul automatique du montant total.
- Sauvegarde du panier avec `localStorage`.

### 🔮 Opening Chamber
- Ouverture des boosters.
- Tirage de cartes selon leur rareté.
- Animation de révélation.
- Mise en valeur des cartes rares et légendaires.
- Ajout des cartes obtenues à la collection.

### 📚 Grimoire
- Consultation de la collection.
- Filtres par type et par rareté.
- Affichage des détails des cartes.
- Compteur de cartes découvertes.

### ⚔️ Deck
- Ajout et suppression de cartes.
- Limite de 20 cartes.
- Un seul exemplaire de chaque carte.
- Affichage des statistiques du deck.
- Sauvegarde du deck avec `localStorage`.

*Les fonctionnalités ci-dessus constituent les objectifs du projet ; leur disponibilité dépend de l'état actuel du développement.*

## 🚀 Installation et lancement

### 1. Cloner le dépôt GitHub

```bash
git clone https://github.com/souladah/Mythoria-projet.git
```

### 2. Accéder au dossier

```bash
cd Mythoria
```

### 3. Ouvrir le site

Ouvrir `index.html` dans un navigateur ou utiliser l'extension **Live Server** de Visual Studio Code.

Tailwind CSS est chargé depuis son CDN dans `index.html`. Une connexion Internet est nécessaire pour charger Tailwind.
